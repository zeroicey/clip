# clip — 网络剪贴板

在两台机器之间搬文本或截图，只需要一个网址。是想做 **webnote.cc 的开源版本**。

```bash
# 机器 A：打开 https://clip.hcyj.xyz/ops1 ，写下内容，会自动保存
# 机器 B：打开同一个网址，全选复制
curl https://clip.hcyj.xyz/ops1/raw          # 或者命令行直接拿
```

场景是 Linux 运维时最烦的那件事：两台机器之间有网络，但文件不好传、命令不好执行。
把要搬的东西放在这个网站上，在另一台机器的浏览器里打开、复制、粘贴。
**不需要账号，不需要装任何东西。**

它不为 AI 设计、没有 API key、没有 AI 接口 —— 这是给人用的。AI 报告发布是另一个项目
（teleport），在它自己的仓库里。

## 怎么用

1. 打开 `https://clip.hcyj.xyz/` ，随便打一个后缀（只能用 `a-z 0-9 - _`，最长 32 字符），
   点「打开」。或者在地址栏直接敲 `https://clip.hcyj.xyz/任意后缀`。
2. 写出你要搬过去的内容 —— **停手就自动保存**（也可以点「保存」）。
3. 在另一台机器上打开同一个网址：全选复制即可。图片会以缩略图显示，点开看原图。
4. 命令行：`curl https://clip.hcyj.xyz/ops1/raw` 拿到纯文本，图片是 `/raw/0`、`/raw/1`…
5. 两边都开着这个页面时会**自动同步**（几秒内），不需要刷新。

默认 **24 小时**后自动清空（创建时可以说要多久，说 `0` 就是永不过期）。
内容上限：文本 256 KiB，图片单张 5 MiB、最多 4 张。

## 公开还是私密：要不要设密码

**没设密码时，这份剪贴板是完全公开的**：知道后缀的人**都能读，也都能改**，而且
**任何人都能给它设一个密码、把它变成自己的**（之后就归那个知道密码的人了）。
所以：别把机密放在没设密码的后缀里，也别用太好猜的后缀。

设了密码之后，只有知道密码的人能读、能改、能换密码。要点：

- 密码只存 argon2id 哈希（单向、不可解密），明文永不入库、不回显、不进日志。
- **密码挡全部四个读入口** —— 页面、`/raw`、`/raw/N`、`/api/clips/:后缀`。
  命令行读带密码的内容：

  ```bash
  curl -H 'X-Clip-Password: 你的密码' https://clip.hcyj.xyz/ops1/raw
  ```

- **忘了密码就找不回来了** —— 没有找回流程，也没有“重置”。只能等它过期（或换一个后缀重来）。
- 密码走请求头或请求体，**从不进 URL**（URL 会进访问日志、浏览器历史和 Referer）。
- 猜密码会被限流（按地址 + 按后缀两个维度），但**短密码 + 短后缀仍然可以爆破** ——
  要真保密就用长密码。

## 只读分享链接（`/s/<token>`）

想给同事看其中一段、又**不想把主密码给他、也不想他能改**？在页面下方展开
「分享（只读链接）」创建一个：

- 地址是 `https://clip.hcyj.xyz/s/<token>`，token 是服务端生成的随机串（不是你的后缀）。
- **天生只读**：`/s/...` 上根本没有写入口 —— 写形状的请求直接 405，不是“把按钮藏起来”。
- **口令独立于主密码**：知道分享口令就能看，**不需要主密码** —— 这正是它存在的理由。
  创建时选一种形态：
  - **仅链接**：拿到链接就能看（内容仍然只读）；
  - **分享密码**：你自己设，长期有效；
  - **6 位取件码**：服务端生成（像快递柜取件码），**只显示一次**、短时有效
    （默认 30 分钟，且不会超过这份剪贴板自己的过期时间）。
- 分享**不复制内容**：它和主入口指同一份，主人改了、分享方刷新（或几秒内自动）即见。
- **可撤销**：主人在页面上点「撤销」，对方的页面**立刻**失效。
- 分享的纯文本入口同样用 `X-Clip-Password` 头（取件码也放这个头）：

  ```bash
  curl -H 'X-Clip-Password: 分享口令' https://clip.hcyj.xyz/s/<token>/raw
  ```

- 分享口令只存 argon2id 哈希，**忘了只能撤销重来**；猜口令按 `ip:<地址>` 与 `share:<token>`
  两个桶限流，且只对失败计费。
- 6 位取件码只有 100 万种可能，所以它**必须**配短时有效 + 尝试上限 —— 别把它当长期密码用。

> 分享到页面上的内容**不回显你的后缀**：`/s/<token>` 只认 token，所以拿到分享链接的人
> 推不出（也猜不到）你平时用的那个网址。

## 它是怎么工作的

```text
浏览器 ──https──> clip.hcyj.xyz
                    │
     hcyj (阿里云广州)  Caddy :443   ← 终止 TLS、只做转发
                    │  reverse_proxy 172.17.0.1:8790
                    │
                  frps :7000  ◄── 隧道由本机主动拨出（Tailscale/EasyTier 到 hcyj）
                    │
     hpcore (佛山电信)  frpc ──> 127.0.0.1:8790  clip (systemd)
                    │
                  PostgreSQL (本机容器, database `relay`)
```

**为什么后端在本机、公网入口在 hcyj**：本机在电信 NAT 后面，入向不可达（而且 hcyj →
本机的入向 TCP 是死的），所以由本机主动拨出 frp 隧道到 hcyj，hcyj 负责证书与转发。
代价是本机的可用性决定了服务的可用性。

**为什么剪贴板独占一个子域名**：第一个路径段就是后缀本身
（`https://clip.hcyj.xyz/ops1`）。前缀会把这个卖点吃掉 —— 短到能从一个屏幕念到另一个屏幕，
是这个功能存在的理由。

## 安全模型（读之前先知道）

| 面 | 处理 |
| --- | --- |
| 读 | 没有密码时**永远匿名**（这是设计目标，不是缺陷）；设了密码则要密码 |
| 写 | 没有密码时**谁都能写**；“设密码”本身就是所有权声明（先设先得） |
| 密码 | argon2id PHC 哈希入库（19 MiB / 2 轮，自带 salt）；明文不落盘、不回显、不进日志 |
| 密码传递 | `X-Clip-Password` 头（读/写）或 `POST /api/clips/:后缀/unlock` 的请求体；**从不进 URL** |
| 忘密码 | **不可恢复**（无账号、无找回流程），只能等过期或换后缀 |
| 写判定 | 写在写语句的 `WHERE` 里（把“刚校验过的哈希”当条件），不是 read-then-write |
| 猜密码 | 按 `ip:<地址>` 与 `suffix:<后缀>` 两个桶限流；**只对失败计费** |
| 分享 | `/s/<token>` 只挂 GET/HEAD（写入口在路由层就不存在）；口令**独立于主密码**、不回显后缀 |
| 分享撤销 | 删掉那条凭据即失效（`on delete cascade` 让 clip 没了分享也一起没） |
| 分享口令 | 同样 argon2id 入库；取件码只回显一次、短 TTL + 按 `ip:`/`share:<token>` 限流 |
| 内容渲染 | 一律纯文本（`textContent`），绝不 `innerHTML`；per-response nonce CSP，无 `unsafe-inline` |
| 上锁的页面 | **不把正文渲进 HTML**（渲成壳，解锁后走 API 拉）；否则密码只是装饰 |
| 图片 | 类型从**字节**嗅探，只允许 PNG/JPEG/GIF/WebP（SVG 是可执行文档，明确拒绝） |
| 滥用 | 按 IP 写限流（默认 30/小时）+ 全局配额（2 万条 / 1 GiB，满了**关闭写入**）+ 全局 kill switch |
| 爬虫 | `X-Robots-Tag: noindex` + `robots.txt` 全站 Disallow（被索引的后缀等于被公开） |
| 日志 | 服务端只记 method/path/status/bytes/requestId，**不记任何请求头**（密码走 header） |

> 运营者能读到未加密的正文。密码挡的是“猜到后缀的人”，不是“服务运营者” ——
> 要连运营者也读不到，需要端到端加密（见 `.ai/decisions/2026-10-16-clip-access-password.md` 里的 B 方案）。
